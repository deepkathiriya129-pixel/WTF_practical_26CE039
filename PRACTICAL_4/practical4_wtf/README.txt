PRACTICAL 4 - DOM Manipulation and Event Handling

Files:
1. index.html
2. practical4.js

How to run:
1. Keep index.html and practical4.js in the same folder.
2. Open index.html in a browser.
3. Try every button, input, select box and mouse interaction.
4. Open browser Developer Tools -> Console if you want to inspect JavaScript errors.

Concepts included:
- getElementById()
- getElementsByClassName()
- getElementsByTagName()
- querySelector()
- querySelectorAll()
- innerHTML
- setAttribute()
- style
- createElement()
- appendChild()
- replaceChild()
- removeChild()
- click
- dblclick
- mouseover
- mouseout
- keydown
- keyup
- change
- theme switching
- image preview
- dynamic menu
